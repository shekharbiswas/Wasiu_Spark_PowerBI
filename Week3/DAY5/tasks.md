# Week 3, Day 5 — Tasks ( 6 Hrs )
## Build Your "What Is Kafka?" Presentation in Canva




No coding today. You're building a short slide deck that explains Kafka and recaps what you built this week. Follow each step in order.

---

## Task 1 — Set Up Canva
1. Go to **canva.com**.
2. Sign up for a free account (or log in if you already have one).
3. Click **Create a design** → search for **Presentation** → choose a simple, clean template (avoid busy/colorful ones — simple is easier to read).
4. Rename your design at the top-left to `What is Kafka - [Your Name]`.

---

## Task 2 — Slide 1: Title Slide
1. Keep or edit the title text box to say: **"What Is Kafka?"**
2. Add a subtitle text box underneath: your name and "Week 3 — Streaming Basics."
3. That's the whole slide — don't overload the title slide with content.

---

## Task 3 — Slide 2: Batch vs. Streaming
1. Click the **+ (Add page)** button at the bottom to add a new slide.
2. Add a heading text box: **"Batch vs. Streaming."**
3. Add two text boxes side by side (search "text box" in the left Elements panel and drag one in, then duplicate it):
   - Left box: **"Batch — data sits still, you load it when ready"**
   - Right box: **"Streaming — data arrives continuously, you react as it happens"**
4. Optional: search "arrow" in Elements and drag a simple arrow between the two boxes.

---

## Task 4 — Slide 3: The Four Core Terms
1. Add a new slide.
2. Add a heading: **"Kafka's Core Building Blocks."**
3. Add four short text boxes, one per term, in your own words (keep each under 1 sentence):
   - **Topic** — a named channel events flow through
   - **Producer** — sends events into a topic
   - **Consumer** — reads events out of a topic
   - **Broker** — the server that stores and manages topics
4. Optional: search "flow" or "process" in Elements to find a simple arrow/box diagram, and arrange the four terms left to right in the order data flows through them (Producer → Topic → Consumer).

---

## Task 5 — Slide 4: What I Built This Week
1. Add a new slide.
2. Add a heading: **"What I Built."**
3. Add four short bullet points (use the bullet list text option), one per day:
   - Day 1 — Explored a live Kafka topic and watched messages arrive
   - Day 2 — Built my own Kafka cluster and topic, and wrote a producer to send real data
   - Day 3 — Connected Databricks to read my stream live using `readStream`
   - Day 4 — Grouped streaming data into 1-minute windows and summed Sales live

---

## Task 6 — Slide 5: What I Learned
1. Add a new slide.
2. Add a heading: **"What I Found Most Interesting."**
3. Write 2–3 sentences, in your own words, about whichever part of the week surprised you most or clicked the best. There's no right answer — this is your personal takeaway.

---

## Task 7 — Clean Up and Export
1. Click through all 5 slides once and check: is there any slide with more than 4–5 short lines of text? If so, trim it down.
2. Click **Share** (top-right) → **Download** → choose **PDF Standard**.
3. Save the PDF somewhere you can find it — this is your Week 3 deliverable.
