## Quick Recap (30 Seconds)
- **Calculated column** → one value per row, stored in the table. Use `TableName[Column]` syntax.
- **Measure** → summarizes rows based on whatever's filtered. Use `SUM()`, `COUNTROWS()`, `AVERAGE()`, `DIVIDE()`.
- Measures can reference other measures: `[Total Sales]` inside another formula.

If any of that feels unfamiliar, re-read Day 3's Concepts doc before starting today's tasks — today is pure practice, not new material.
